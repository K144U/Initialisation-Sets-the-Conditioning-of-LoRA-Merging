## 1. What the paper claims, as of now

Whether the $T$ adapters of a LoRA cohort shared one random draw of the $A$
factor determines the conditioning of $\bar H$ across four orders of
magnitude. That is invisible to merging methods that average or sparsify, and
decisive for methods that solve a linear system, where one Tikhonov term is
the difference between a working merge and a model that scores zero. It is
measurable from the weight files in about a CPU minute, and it holds for
$37.8\%$ of $45$ public cohorts under a pre-registered sampling frame.

The rate-distortion bound is **provenance, not a contribution**: it is why we
looked at $\bar H$. Its floor term is exactly zero on every real cohort, its
rate term rests on an unproven assumption and an imported constant, and its
exponent is unmeasurable on our grid. It lives in Appendix A. Do not promote
it back to the main text.

## 2. The discipline, which is the paper's actual currency

Every empirical claim is governed by a pre-registration committed **before**
the compute it governs. There are ten, in `notes/prereg_*.md`, reproduced in
the supplementary material and summarised in Appendix F with a commit table a
reviewer can check with `git merge-base --is-ancestor`.

Rules that have never been broken and must not be:

- **Register before generating.** The registration commit must precede the
  generator commit, which must precede any cell.
- **Never move a threshold after seeing data.** If one moves, the result is
  reported as exploratory and the registration is void.
- **Report the branch the rule lands in**, including the branches that cost
  us a contribution. Every registration writes all its branches in advance.
- **No partial reads.** Analyzers refuse to report until every cell exists.
- **An amendment may only make our own predictions harder**, never easier,
  and must be committed before any cell it governs runs.

If you find yourself wanting an exception, the answer is to report the
limitation instead.

## 5. Traps that have each cost real time

- **The orchestrator skips done cells** (`Path(cell["done"]).exists()`), which
  is why `qdel` and resubmit is safe.
- **Inline heredocs and f-strings mangle backslashes on this setup.** Write
  Python to a file and run the file. This has bitten repeatedly on LaTeX
  edits.
- **`knots` with `inner_combination: linear` is algebraically Task
  Arithmetic** ($VV^\top = I$ cancels). The repaired method is `knots_ties`.
  Anything citing "KnOTS" must say which.
- **The two downstream harnesses store per-example records under different
  schemas.** GSM8K uses `gen_text`/`gold`/`pred`/`score`; HumanEval uses
  `task_id`/`score`/`err`/`gen_raw`. Reading one with the other's keys
  reports 100% empty on a cell scoring 0.81. And `err` is the unit-test
  traceback for a wrong answer, not a harness failure: counting non-empty
  `err` as a discard flags a clean cell as 48% discarded.
- **The metric key is `metric_score`,** not `metric_value`.
- **Streaming data loading takes an unshuffled prefix** unless
  `stream_shuffle_buffer` is set. This is the translation-adapter bug. The
  default stays 0 so committed configs still reproduce.
- **HuggingFace API pagination is in the `Link: rel="next"` header,** not the
  body. Reading a cursor off the body silently stops at 100 models.
- **`git-filter-repo` rewrites hashes inside commit messages,** so subjects
  differ between the working repo and the bundle. `remap_commit_table.py`
  masks hex before matching.
- **The anonymiser can leak through its own source.** The leak-pattern line
  lives inside the bundle it scans and will match itself; a rebuild once
  reported clean while `95154157` and `+0530` were still present.
- **Untracking a file does not remove it from history.** A committed bundle
  took the next bundle from 19 MB to 60 MB; the fix is `--path` exclusions.

## 6. Never do these

   to $B^2/(4 d_{\rm eff})$, which is never derived and contradicts Lemma 2.

   That produced the 60-fold floor difference we had to withdraw.
3. Promote the rate-distortion bound back to a contribution.
4. Reinstate the benchmark-confounding claim using the margin-aware control.
5. Edit a pre-registration after the fact. Their stale internal references are
   the evidence they are unedited.
6. Force-push or amend published history on `phase3-bootstrap`.
7. Add `[accepted]` or `[preprint]` to `\usepackage{tmlr}` before acceptance.
