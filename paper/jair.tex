% JAIR build root. Fourth venue root alongside tmlr.tex, arxiv.tex and
% iclr2027.tex, and the only one that is NOT anonymous.
%
% JAIR's stated policy hides reviewers from authors and says nothing about
% hiding authors from reviewers, and their own template carries a full author
% block with names, emails, ORCIDs and affiliations. So this build shows the
% authors. Confirm at the submission wizard before uploading; if it turns out
% they want a blinded PDF, acmart takes an "anonymous" class option and
% jair.cls forwards unknown options straight through to it.
%
% Three option passes have to happen BEFORE \documentclass, because jair.cls
% loads acmart which loads all three packages itself. Requesting an option
% later that the earlier load did not receive is an option clash, and in
% xcolor's case the clash is silent in the worst way: [table] gets dropped,
% colortbl never loads, \cellcolor is undefined, and every shaded cell in the
% result tables prints a literal "green!18". Same trap that is documented in
% iclr2027.tex and tmlr.tex, one class deeper.
\PassOptionsToPackage{table}{xcolor}
\PassOptionsToPackage{T1}{fontenc}
\PassOptionsToPackage{utf8}{inputenc}

% acmthm=false is load-bearing, not tidiness. acmart defines its own theorem,
% lemma, corollary, proposition and definition environments numbered
% \newtheorem{theorem}{Theorem}[section], i.e. per section. This paper's prose
% refers to "Lemma 2", "Theorem 3" and "Remark 5" by absolute number and
% preamble.tex deliberately runs one shared counter across all of them. Under
% acmart's defaults those references would silently renumber to 3.1, 4.1 and
% so on, every cross-reference in the theory sections would point somewhere
% else, and nothing would error. Suppressing acmthm lets preamble.tex keep the
% single counter it declares.
%
% manuscript+review are the submission options from JAIR's own example file.
% For a camera-ready both come off and the class is used bare.
\documentclass[manuscript, screen, review, acmthm=false]{jair}

% COMPILE TIME. acmart loads microtype bare (acmart.cls:282), which on pdfTeX
% switches on both protrusion and font EXPANSION. Expansion builds a family of
% stretched instances for every font shape in use, and this paper uses a lot of
% them (libertine roman, biolinum sans, inconsolata tt, each in several
% weights). It is the single most expensive thing in the run and it is why
% Overleaf's timeout kills the second pass.
%
% Protrusion is kept: it is nearly free and does most of the visible work.
% Expansion only changes justification slightly, so nothing in the paper's
% content or layout depends on it. Turn it back on for the camera-ready, where
% there is no timeout to fight.
\microtypesetup{expansion=false}
